# Healthsync Backend

Backend for a healthcare appointment-management platform.

**Tech Stack:** Node.js, Express.js, MongoDB, Mongoose, JWT.

**Features:**

- Patient and doctor authentication
- Doctor verification
- Appointment and schedule management
- Payment integration
